📚 NovelCraft

Transform messy Chinese novels and text files into beautifully structured ebooks.

NovelCraft is a browser-based toolkit designed for processing, translating, formatting, and converting online Chinese novels and text files.

Turn messy downloaded novel text into clean, organized, professional-looking content — then convert it into a properly structured EPUB ebook.

---

🛠️ Features

📄 TXT → EPUB

Convert plain-text novels into professionally structured EPUB ebooks.

- Automatic chapter detection
- Chapter splitting
- Clean paragraph formatting
- Customizable ebook structure
- Professional EPUB output
- Large text file support

🔄 EPUB → TXT

Reverse the process and extract an EPUB into a single TXT file.

- Preserve chapter order
- Preserve chapter titles
- Preserve readable paragraph structure
- Optional metadata removal
- Optional extra-content filtering

🧹 Novel Text Formatter

Clean messy text downloaded from novel websites.

Advanced processing includes:

- Intelligent line-break fixing
- Automatic chapter splitting
- Paragraph indentation
- Duplicate-line removal
- Website/spam filtering
- Simplified ↔ Traditional Chinese conversion

🌐 Translation

Designed to work with Chinese → English novel translation workflows.

The architecture can support multiple translation providers while keeping the processing workflow organized.

💾 Local-First

Whenever possible, files are processed directly in the browser.

Your local novel files do not need to be uploaded to a server just to perform basic processing.

🚀 Technology

NovelCraft is designed as a modern browser-based application.

Core technologies may include:

- HTML
- CSS
- JavaScript / TypeScript
- IndexedDB
- Browser File APIs
- EPUB processing libraries
- Client-side text processing
- Client-side translation integrations where applicable

The project is designed to be compatible with static hosting such as GitHub Pages whenever features do not require a backend.

---

📱 Browser Based

No traditional desktop installation is required.

The application is designed to work across:

- 📱 Mobile
- 💻 Desktop
- 🖥️ Large screens

The interface adapts to different screen sizes while keeping complex tools easy to use.

---

🔐 Privacy

NovelCraft follows a local-first approach wherever possible.

Basic file-processing operations are designed to happen directly in the browser.

This means files such as:

- TXT
- EPUB
- Novel manuscripts

can be processed locally without automatically uploading them to a server.

Translation or external services may require network communication depending on the provider being used.
